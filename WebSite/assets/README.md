# assets/

Recursos estáticos: imágenes, hojas de estilo globales y scripts
transversales.

- `css/` — Hojas base (variables, layout, reset). Los estilos de cada
  componente viven en `../components/`.
- `js/`  — Lógica de páginas y capa de datos mock.
- `img/` — Imágenes de productos, fotos comunitarias, íconos.

Ver los README de cada subcarpeta para más detalle.
