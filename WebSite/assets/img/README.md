# assets/img/

Acá se colocan las imágenes de los productos, fotos de la comunidad,
íconos y piezas gráficas del sitio.

Convención de nombres sugerida:

- `product-{id}.webp` — Foto principal de cada producto.
- `community-{id}.webp` — Aportes de la galería comunitaria.
- `icon-*.svg` — Íconos SVG del UI.
- `logo-*.svg` — Variantes del logo Kyro.

Mientras se incorporan las imágenes reales, los archivos usan
`placeholder.svg` como referencia.
