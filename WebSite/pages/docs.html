Documentación de Kyro

Esta sección explica cómo usar el sitio de Kyro como plantilla y cómo está construido el código. También describe el proceso manual de producción de la ropa.

Guía de Instalación

Esta web está construida como un sitio estático sin dependencias de build. Eso significa que podés clonarla, personalizarla y servirla en cualquier hosting con apenas unos pocos comandos.

Requisitos

  • Un navegador moderno (Chrome, Firefox, Safari, Edge).
  • Opcional: Python 3, Node.js o cualquier servidor estático.

Pasos

  1. Cloná el repositorio: 
    git clone https://github.com/eldomiinus/Kyro-WebSite.git
  2. Entrá a la carpeta del sitio: 
    cd Kyro-WebSite/WebSite
  3. Servila localmente: 
    python3 -m http.server 8080
  4. Abrí el sitio en http://localhost:8080.
Tip: Como no hay build, los cambios que hagas en index.html, los CSS o los JS se reflejan instantáneamente con un refresh del navegador.

Estructura del Proyecto

El código está organizado en módulos independientes. Cada archivo tiene una única responsabilidad y expone una API global bajo window.KYRO*.

Árbol de carpetas

WebSite/
├── index.html              → Página de inicio
├── pages/                  → Catálogo, producto, comunidad, recursos, cuenta, docs, blog, wishlist
├── components/             → Componentes UI (navbar, footer, cart, wishlist, …)
│   ├── navbar.js / navbar.css
│   ├── footer.js / footer.css
│   ├── cart.js   / cart.css
│   ├── wishlist.js / wishlist.css
│   ├── filters.js / filters.css
│   └── …
├── assets/
│   ├── css/main.css        → Variables, reset, layout base
│   ├── js/                 → Capa de datos y lógica de páginas
│   └── img/                → Imágenes (placeholders por ahora)
└── README.md

Capas

  • Datos (assets/js/data.js): única fuente de productos, comunidad y recursos. Se reemplaza por la API.
  • Componentes: navbar, footer, cart, wishlist, filters. Reusables en todas las páginas.
  • Páginas: un .js por página que renderiza su contenido en un contenedor.
  • Bootstrap (main.js): detecta la ruta actual y dispara la lógica correspondiente.

Cómo añadir una nueva página

  1. Creá pages/mi-pagina.html con la estructura base.
  2. Creá assets/js/mi-pagina.js que exponga window.KYROMiPagina.
  3. Agregá el <script> y un caso en main.js.

Proceso de Creación

Toda la ropa de Kyro se hace a mano, pieza por pieza. Este es el flujo general que seguimos para producir cada prenda, desde la selección del textil hasta el empaquetado.

1. Selección del textil

Trabajamos con remeras de algodón e hilos aptos para estampa. El textil se compra al por mayor para reducir costos y mantener los precios accesibles.

2. Diseño y serigrafiado

Los diseños nacen como archivos abiertos (SVG, PNG de alta resolución) que después se suben a la sección de Recursos Open Source para que cualquier persona pueda replicarlos.

3. Curado y empaquetado

Cada pieza se inspecciona, se dobla y se embala en envoltorio reciclado. La etiqueta incluye el nombre del producto, su costo desglosado y un QR que dirige a la página individual del producto, donde se ve el desglose de costos completo.

4. Distribución

Las prendas se entregan en mano en la ciudad o se envían por correo. Los costos fijos (envío, mantenimiento de sitio, estampas) están desglosados en cada producto.

La sección Transparencia de Costos en la página de cada producto es la columna vertebral de Kyro: no es un detalle más, es el corazón del proyecto.
